# Heart-Disease-Prediction-Using-Machine-Learning
Machine learning models (Logistic Regression &amp; Decision Tree) for heart disease prediction using clinical data

Heart disease is one of the leading causes of death worldwide, making early prediction an important step toward improving patient outcomes. In this team project, we developed and compared machine learning models to predict the likelihood of heart disease using clinical patient data.

We performed data exploration, preprocessing, duplicate checking, categorical encoding using One-Hot Encoding, feature scaling with StandardScaler, and outlier treatment using the IQR method without removing records. We then trained and evaluated both Logistic Regression and Decision Tree models, optimizing their parameters before comparing their performance.  

The Decision Tree model achieved the best overall performance with 87.5% accuracy, outperforming Logistic Regression across Accuracy, Precision, Recall, and F1-score. These results demonstrate how machine learning can support early heart disease detection and assist healthcare professionals in making more informed decisions.  

Tools & Technologies: Python, Pandas, NumPy, Matplotlib, Scikit-learn, Google Colab, Kaggle.
